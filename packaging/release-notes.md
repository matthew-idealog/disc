DISC is a terminal client for Subsonic-compatible music servers. See [CHANGELOG.md](https://github.com/matthew-idealog/disc/blob/main/CHANGELOG.md) for what's new and [README.md](https://github.com/matthew-idealog/disc/blob/main/README.md) for setup.

## Downloads

### Windows (`disc-windows-x86_64.zip`)

1. Unzip and run `disc.exe` from Windows Terminal or PowerShell (double-clicking also opens it in a console window).
2. The first time, Windows SmartScreen may say "Windows protected your PC" because the app is not code-signed. Click **More info → Run anyway**.

### macOS (`DISC-macos.zip`, Apple Silicon and Intel)

1. Unzip and move `DISC.app` to Applications. Opening it starts DISC in a Terminal window.
2. The first time, macOS will say Apple could not verify DISC because it is not notarised. Click **Done**, then go to **System Settings → Privacy & Security**, scroll down and click **Open Anyway** next to DISC.
